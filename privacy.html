privacy policy

what hollow stores, why it stores it, who can see it, and how you can get it deleted.

last updated: october 25, 2026

the short version

  • hollow only stores what it needs to run the features a server turns on.
  • we never sell, rent or trade your data, and we don't use it for ads.
  • hollow doesn't keep a record of normal chat messages.
  • you can delete everything about you any time with ,deletedata me.
  • server owners can delete everything about their server with ,deletedata server.
  • if hollow is removed from a server, that server's data is deleted automatically after 30 days.

1. who we are

hollow is a discord bot that servers add to get moderation, tickets, music, levels, giveaways and other features. it is run by an independent developer, not by discord. in this policy "we" means the people who run hollow, and "you" means anyone who uses hollow or is in a server that has it.

by using hollow or being in a server that uses it, you agree to this policy and to our terms of service.

2. what we store

everything hollow stores is tied to discord ids (numbers discord gives every user, server, channel and role). most of it only exists because a server turned a feature on.

server settings

everything a server sets up in hollow: prefixes, dashboards, channels and roles picked for features, custom messages and their looks, autoresponders, tags, shop items, reskin choices and so on.

logs to find bugs

  • command logs: when you run a command, hollow may log the command text, your username and id, the server and the channel to a private channel only the bot owner can see. this is used to find bugs and abuse.
  • error reports: if a command breaks, hollow sends the error, the command that was run, who ran it and the server to the bot owner so it can be fixed.

3. what we don't store

  • we don't keep a history of normal chat messages. hollow reads messages to make features like automod, autoresponders, counting and levels work, then lets them go.
  • deleted and edited message snipes only live in memory for a short time and are gone on restart.
  • images you use with image commands, and media hollow reposts, are processed and not kept.
  • we don't store passwords, payment details, ip addresses, your location or anything from outside discord.
  • log channels a server sets up post to that server's own channels. those messages belong to the server, not to us.

4. why we store it

  • to make the features work, like remembering your xp, your ticket or a server's settings.
  • to keep servers safe, like moderation history, automod, anti raid and antinuke.
  • to fix bugs and stop abuse of the bot.

we don't use your data for advertising, profiling, selling, or training ai models.

5. who can see it

  • server staff can see what hollow shows in their server, like cases, tickets, reports, applications and modmail. staff of a server are responsible for how they use it.
  • server admins can see who sent a confession in their server.
  • the bot owner can access stored data to run the bot, fix bugs and handle abuse.
  • nobody else. we don't sell, rent, trade or share your data, unless the law requires it.

6. other services hollow uses

some features send a search or link to an outside service to get an answer. only what's needed for that request is sent, never your account details.

  • discord runs the whole platform hollow works on.
  • youtube, twitch, spotify, soundcloud and similar sites for music, alerts and lookups.
  • tiktok, instagram, youtube and twitter through public tools, only when someone reposts a link.
  • urban dictionary, google translate, mymemory, open-meteo, roblox, crypto price and trivia services when someone uses those commands.

those services have their own privacy policies, which apply to what they receive.

7. how long we keep it

  • data stays while the feature it belongs to is in use, or until you or the server delete it.
  • if hollow leaves or is kicked from a server, everything for that server is deleted after 30 days. if hollow is added back within 30 days, it's kept.
  • ended giveaways are removed after 7 days.
  • we keep daily backups of the database for up to 14 days so data can be restored if something breaks. deleted data disappears from backups once they rotate out.

8. deleting your data

,deletedata me deletes everything stored about you in every server, like your xp, warnings, invites, voice time, economy, birthday and personal settings.
,deletedata server deletes everything hollow stores for a server. only the server owner can run it.

you can also see a short summary of what's stored with ,privacy. if you can't use the commands, contact us (see below) and we'll delete it for you.

some things live in a server's own discord channels, like ticket transcripts or log messages. those are controlled by that server and can't be deleted by hollow.

9. keeping it safe

data is stored on a private server that only the bot owner can access. we limit what's stored to what features need, and access is never shared. no system is perfectly secure, but we take reasonable steps to protect your data.

10. age

you must meet discord's minimum age to use discord, and so to use hollow. hollow doesn't knowingly collect data from anyone under that age. if you think it has, contact us and we'll delete it.

11. changes to this policy

we may update this policy when hollow changes. the date at the top shows the latest version. big changes are announced in hollow's update messages. using hollow after a change means you accept the new version.

12. contact

for questions about your data or this policy, use ,feedback in any server with hollow, or join the hollow support server.
